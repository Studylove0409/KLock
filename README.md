# KLock — 菜单栏里随手就有的计时器

[![License: GPL-3.0](https://img.shields.io/badge/license-GPL--3.0-blue.svg)](https://www.gnu.org/licenses/gpl-3.0.html)

**KLock** 是一款 macOS 菜单栏计时/提醒工具：按住菜单栏图标往外拖，拖动距离就是计时时长，松手后还能微调一下再开始。不占 Dock、不弹主窗口，起一个计时器只需要一次拖拽。

menu bar timer · drop to clock · reminder · KLock · 菜单栏计时器 · macOS 倒计时

## 功能要点

**拖拽创建**

- 按住菜单栏图标往外拖，拖动距离决定时长，拖动过程中实时显示时长和「预计结束时刻」。
- 拖到 5 / 10 / 25 / 45 分钟附近会自动磁吸，不用拖得很精确。
- 拖拽时可选显示一条从图标连到鼠标的指示线，颜色可在偏好设置里改。

**松手微调**

- 松手后不会立刻跑起来，而是弹出一个微调面板：`−1分` / `−15秒` / `+15秒` / `+1分`。
- `回车` 或点「开始」确认，`Esc` 或点 ✕ 取消。
- 最终时长限制在 1 秒 ~ 7 天之间。

**提醒卡**

- 计时结束时在屏幕下半部弹出毛玻璃提醒卡（不需要屏幕录制权限）。
- 卡片上可直接「稍后提醒」（5 分钟 / 15 分钟）、把已结束的计时器暂停、或删除。
- 30 秒无操作自动关闭，也可以按 `Esc` 关闭。
- 可选播提示音，支持内置音和自定义音，并可循环响铃直到手动停止；菜单里有「停止全部响铃」。

**可控的计时器**

- 菜单栏菜单里直接列出进行中的计时器，可原地暂停 / 继续、或删除。
- 可选让状态栏显示下一个即将结束的计时器。

**历史记录**

- 计时器从创建那一刻就落档，状态分为 进行中 / 已完成 / 已取消。
- 按天分组（今天 / 昨天 / 具体日期），每条可以一键「重跑」，也能整体清空。
- 最多保留 200 条，存在 UserDefaults 里。

**其他**

- 可同步到 macOS「提醒事项」：指定写入哪个列表，删除计时器时同步删掉对应提醒。
- 可选给计时器起名字（偏好设置里开启「自定义名称」）。
- 偏好设置：菜单栏图标可换成自定义文字 / SF Symbol / 备用图标；可设置开机启动、忽略过短的计时器、时长一律按分钟显示等。

## 安装

系统要求：**macOS 13.0（Ventura）及以上**。构建只用 Xcode Command Line Tools，不需要打开 Xcode。

```bash
git clone <本仓库地址>
cd Dropclock
bash scripts/build.sh
```

构建产物在 `build/Dropclock.app`（bundle 名沿用构建脚本，当前仍叫 Dropclock）。脚本还支持：

| 参数 | 作用 |
| --- | --- |
| `--run` | 构建后直接启动（会先结束已有的同名进程） |
| `--install` | 拷贝到 `/Applications/Dropclock.app` |
| `--force` | 配合 `--install`，覆盖已存在的应用 |

也可以直接双击 `build/Dropclock.app` 运行。本轮不提供预编译下载包。

## 使用

1. 在菜单栏找到 KLock 图标。
2. **按住图标往外拖**，拖动过程中会跟着显示时长和结束时刻。
3. **松手** → 弹出微调面板 → 确认后开始计时。若开启了「自定义名称」，会先让你填个名字。
4. 点击图标打开菜单，可以管理进行中的计时器、打开历史记录、改偏好设置。

### 拖动距离与时长的对应

| 操作 | 效果 |
| --- | --- |
| 拖不到 50 pt | 不创建计时器 |
| 50 ~ 80 pt | 30 秒起，之后每 1 pt 加 1 秒 |
| 80 ~ 130 pt | 60 秒起，之后每 5 pt 加 30 秒 |
| 130 pt 以上 | 5 分钟起，之后每 5 pt 加 1 分钟 |
| 普通拖拽 | 靠近 5 / 10 / 25 / 45 分钟时磁吸（±10 秒内） |
| 按住 `Control` 拖 | 以 5 分钟为步进（默认启用，可在偏好设置关闭） |
| 按住 `Shift` 拖 | 以秒为步进（需在偏好设置启用「秒模式」） |

## 权限说明

KLock 默认不需要任何系统权限；下面两项都是**按需**申请的：

- **提醒事项（Reminders）**：只有在偏好设置里打开「同步到提醒事项」时才会请求授权，用于写入和删除与计时器对应的提醒。macOS 14 及以上读取列表需要「完全访问」。如果被拒绝，可以在「系统设置 › 隐私与安全性 › 提醒事项」里改回来，偏好设置面板也提供了一键跳转。
- **通知（Notifications）**：用于计时结束时发系统通知。**未授权也不影响应用内的提醒卡片**，偏好设置里会显示当前授权状态并可跳转到「系统设置 › 通知」。

应用**不申请**屏幕录制、辅助功能等其他权限，提醒卡的毛玻璃效果是系统材质自绘的。
